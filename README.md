# 🏺 Turnero Taller de Cerámica

Aplicación web interactiva para gestionar turnos, pagos y asistencias 
de un taller de cerámica. Desarrollada como proyecto final del curso 
JavaScript Flex de Coderhouse.

## Tecnologías usadas
- HTML, CSS, JavaScript (vanilla)
- Tailwind CSS
- SweetAlert2
- Lucide Icons
- LocalStorage como base de datos simulada

## Funcionalidades
- Registro e inicio de sesión de alumnas
- Compra de packs (transferencia, efectivo, Mercado Pago)
- Reserva, reprogramación y cancelación de turnos
- Panel de profesora con gestión de alumnas, calendario y facturación

## Cómo correrlo
Clonar el repositorio y abrir index.html en el navegador.
